Fein Solitaire


Intro

Fein Solitaire is a curated collection of 100+ popular and not-so-much solitaire games.

The top part of the home view displays a list of all available games, sorted by name, with YOUR rating of each one.

You can change the rating by tapping the stars in the selected solitaire bar in the middle of the screen.

The bottom part shows a preview of the currently selected game in the state you left it, or a new game if you never tried it before, and the rules for that game.

You can filter the list by tapping a filter button (three lines in a circle) and toggling the rating of the solitaire to show.

You can also search by name by tapping the search button (magnifying glass) and typing the name of the solitaire you want to play.

The three tabs in the bottom right panel allow you to switch between the summary, therules, and your personal statistics for the selected solitaire.

Tap anywhere in the preview panel to start the game.

Menu

You can control the game through the menu with the following commands:

  • New Game - reshuffle the decks and start a new play.
  • Hint - provide an on-screen hint for all valid moves. The cards that can be moved are outlined in green, the locations where they can be moved to - in yellow. If a card can be moved and another card can be moved on it, it will be outlined in orange.
  • Explain - show and explain all possible moves.
  • Undo - undo, one at a time, your moves.
  • Start Over - undo all your moves and start the same game over.
  • Settings - configure different options the way you like it.
  • Scoreboard - we record the number of times you have this solitaire converged. You can get to the Game Center Leaderboard to compare you score to other players.
  • Designer - open Card Designer to create the deck of cards you like.
  • How To Play - see the documentation.
  • About - brief information about this app, including the links to our website and our Facebook page.

Settings

You can configure different options the way you like it:

Options Tab

Sort Foundations by Suit - sorts where the Aces go in the foundation.

Sort Order - select the order of suits in foundation.

Confirm New Game - ask for a confirmation if you select New Game while in a middle of the game.

Confirm Start Over - ask for a confirmation if you select Start Over while in a middle of the game.

Show Timer - show game timer.

Flipped Card Spacing - you can reduce the overlap for face-down cards.

Deck on left - place deck on the left side of the table.

Show Cards Counter - show how many cards are left in the deck.

Show Errors - show an error message if you attempt an invalid move.

Autocomplete - move all cards to the foundation when solution is obvious.

Animate Deal - show animation while cards are dealt.

Fast Animation - move the cards faster.

 

Toolbar Tab

Select the commands you would like to be presented on the toolbar.

Gestures Tab

Assign your favorite commands to any of the eight recognized gestures. Select if you don’t want to use that gesture.

Card Designer

This is an app within the app. A powerful card designer that allows you to chose the way YOUR cards look on your device. Seven tabs across the top select the feature to be edited. All dimentions are defined as a fraction of the current card height.

  • Front

- Wide Cards: if toggled, use Poker-sized cards (2.5" x 3.5"), otherwise Bridge-sized (2.25" x 3.5").

- Vintage: toggle to apply a vintage-looking texture to the cards.

- Vintage Opacity: select the strength of this effect.

- Front color: tap the circle to bring up Apple’s Color Picker.

- Diamond/Heart color: select a color for the Diamond and Heart suits.

- Club/Spade color: select a color for the Club and Spade suits.

 

  • Index

- Font: select a font to draw card’s rank.

- Split Index: toggle to split the index by drawing a suit symbol on the opposite side instead of under the rank.

- Bottom Index: toggle to show index at the bottom, untoggle to hide.

- Flip Bottom Index: toggle to draw bottom index upright.

- Weight: select a font weight, from Ultralight to Black. Some of the fonts may not support it.

- Font Height: select a font height for the card’s rank.

- Index Size: select a size for the card’s suit.

 

  • Index Pos

- Rank Top: select an offset from the top of the card to the rank.

- Rank Side: select an offset from the left edge of the card to the rank.

- Suit Top: select an offset from the top of the card to the suit.

- Suit Side: select an offset from the left edge of the card to the suit.

 

  • Pip Cards

- Single Pip - select to show single suit symbol for number cards.

- Pip Size: select the size of the pip simbols.

- Pad Horz: select horizontal padding on each side of the pip area.

- Pad Top: select padding on top of the pip area.

- Pad Bottom: select padding at the bottom of the pip area.

 

  • Face Cards

- New Faces: select one of two designs for the Court cards.

- Single Pip Face: select to draw a single pip instead of the face.

- Half Face: select to draw only top half of the face.

- Box Face: select to draw a box around faces.

- Saturation: adjust color saturation of the face card images.

- Pad Horz: select horizontal padding on each side of the face.

- Pad Top: select padding on top of the face.

- Pad Bottom: select padding at the bottom of the face.

 

  • Back

- Back Color: select a color for the card back (border).

- Fill Color: select a color for the middle part of the card back (pattern).

- Invert: toggle to draw pattern in white instead of black.

- Border Width: select the width of the border.

- Pattern: select one of the available patterns.

 

  • Table

- Start Color: select a base color for the table.

- End Color: select a different color if you want a gradient.

- Break Point: specify a portion of the screen to have solid Start color.

- Radial Gradient: toggle to use radial gradient instead of linear.

- Table Image: select which of the loaded images to use for the table background.

- Load Custom Image: tap to load a custom image from Files.

- Select a Photo: tap to load a photo from your library.

 

  • Button Bar

- Save Design: save the current design on your devicce or on iCloud.

- Share Design: share the current design with your friends by any available means.

- Load Design: load previously saved design from your device or from iCloud.

- Reset Small: reset the design to default suitable for the small print cards.

- Reset Large: reset the design to default suitable for the large print cards.
